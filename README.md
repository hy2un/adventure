# 🪐 북플래닛 (Book Planet)

## 1. 프로젝트 소개

북플래닛은 청소년의 독서 습관 형성과 집중력 향상을 돕는 독서 활동 지원 프로그램이다. 독서 기록, 목표 관리, 집중 사운드, 게임을 결합하여 독서에 대한 흥미를 높이고 능동적인 독서 활동을 유도하고자 개발하였다.

## 2. 사용법

1. 웹사이트에 접속하여 회원가입 및 로그인을 진행한다.
2. 도서 검색, 인기 도서 추천 또는 직접 입력을 통해 활동 도서를 선택한다.
3. 이동 버튼을 이용해 캐릭터를 원하는 독서 활동 공간으로 이동시킨다.
4. 사이드바에서 원하는 페이지를 선택하여 각 기능을 이용한다.

## 3. 주요 기능 설명

### MAIN. 도서 활동
- 회원가입 및 로그인
- 도서 검색 및 인기 도서 추천
- 캐릭터 이동을 통한 독서 활동
- 한줄평 및 독후감 작성 및 저장
- 나만의 책갈피 제작 및 PNG 다운로드
- 외부 데이터베이스를 활용한 사용자별 기록 저장

### PAGE 0. 독서 성장 기록
- 개인별 독서 활동 기록 조회
- 월간 독서 목표 설정 및 달성률 확인
- 독서 진도 및 완독 여부 관리
- 달력을 통한 독서 활동 시각화

### PAGE 1. 독서 집중실
- 스톱워치를 활용한 독서 시간 측정
- 시작, 일시정지, 재개 및 초기화
- 백색소음, 싱잉볼, 빗소리 선택
- 집중 사운드 무한 반복 재생 및 음량 조절
- 누적 재생 시간 표시

### PAGE 2. 숏폼 브레이커
- 숏폼 악마로부터 책을 보호하는 방어 게임
- 세 개의 통로를 활용한 전략적 공격
- 숏폼 악마 12개 제거 시 승리
- 방어선 3회 침범 시 패배

## 4. 실행 방법

Python으로 작성한 프로그램을 GitHub에 업로드하고 Streamlit Community Cloud와 연동하여 웹사이트로 배포한다. Neon PostgreSQL을 외부 데이터베이스로 연결하여 사용자별 계정과 독서 활동 기록을 관리한다.

- 개발 언어: Python
- 웹 프레임워크: Streamlit
- 데이터베이스: Neon PostgreSQL
- 외부 API: 도서관 정보나루 API
- GitHub: https://github.com/hy2un/adventure
